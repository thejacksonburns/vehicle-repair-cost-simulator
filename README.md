# Vehicle Repair & Cost Simulator

A data analytics and simulation project that explores how maintenance decisions affect vehicle availability and operating cost.

## Project Overview

The simulator compares different maintenance scenarios by changing factors such as repair crew capacity, spare-parts availability, and delivery delays. It is designed to show the tradeoff between keeping vehicles operational and controlling maintenance costs.

## Tools Used

- Python
- SQLite
- HTML/CSS
- JavaScript

## Analysis

- Runs repeated simulation trials across different maintenance scenarios
- Tracks vehicle availability and associated costs
- Compares the effects of repair crews, spare-parts inventory, and delivery delays
- Helps identify tradeoffs between operational performance and spending
